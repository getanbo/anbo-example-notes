# Security Policy

Report vulnerabilities through GitHub private vulnerability reporting for
`getanbo/anbo-example-notes`. Do not open a public issue containing credentials,
clone URLs, Terraform state, `.anbo/state`, application data, or unredacted
event output.

This repository contains example infrastructure. It is not production security
guidance. The broad local IAM policies are deliberate test fixtures and must be
replaced with least-privilege policies before adapting the project for AWS.
